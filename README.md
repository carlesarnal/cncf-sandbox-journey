# Preparing a CNCF Sandbox Application

A public-record workshop from Apicurio Registry's application, deferral and
onboarding. No software deployment is required. The artifact is an evidence
worksheet a maintainer can apply to their own project.

## Documented sequence

- [2023 application](https://github.com/cncf/sandbox/issues/72): questions about
  integrations and scope; Carles's January 23, 2024 comment deferred the process
  over branding issues and recorded engagement with xRegistry.
- [Renewed application](https://github.com/cncf/sandbox/issues/461): the TOC vote
  passed March 12, 2026. The contribution agreement remained a subsequent step.
- [Onboarding](https://github.com/cncf/sandbox/issues/495): explicit project and
  foundation tasks, not an assumption that a vote completed every transfer.

These records establish what was said and decided. They do not establish that one
technical change caused acceptance, that every application claim was independently
audited, or that Carles personally completed every onboarding action.

Use `worksheet.md`, `PRESENTATION_GUIDE.md` and `presentation.html`. Verify current
foundation requirements before presenting: this is history and a method, not a
permanent statement of admission policy.
